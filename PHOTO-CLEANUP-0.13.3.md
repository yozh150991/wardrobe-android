# PHOTO-03 — очищення та фон фото, 0.13.3

Статус: **verify**, Codex, 9 жовтня 2026. Version code 22; Room/backup 8.

## Поведінка

- Нові фото речей автоматично проходять уточнення маски: м’які краї, видалення дрібних відокремлених залишків та очищення схожих на підтверджений однорідний фон ділянок.
- У редакторі є **«Очистити фон сильніше»**. Після успішної обробки можна повернути звичайний режим. Поки редактор відкритий, повтор використовує тимчасове джерело до першого вирізання. Невдале повторне очищення не підміняє поточне фото.
- У картках, повноекранному зумі та редакторах: білий фон `#FFFFFF`, для білих/майже білих предметів — кремовий `#EEE5D5`. Оцінюються непрозорі пікселі; поле кольору «білий» має пріоритет у картці, деталях і основній формі.
- У пензлі фон також нейтральний; **«Показати сітку прозорості»** дозволяє перевірити фактичну маску. Пензель, crop/rotate й колажі лишаються доступними.
- Збережений PNG лишається прозорим; фон застосовується при показі. Експорт колажу використовує вибраний фон колажу. Окремого flatten/export фото на білий фон немає.
- Для вже збережених фото: відкрити редагування речі → аналіз фото або сильніше очищення → перевірити результат → зберегти. Масова перезаписувальна обробка старих фото не запускається.
- Неякісну маску (весь кадр/майже порожньо) не приймаємо як успіх. Залишається поточне фото й ручне завершення. Підказка кольору/категорії не переписує введені дані автоматично.

## Межі

Це постобробка чинної моделі ML Kit; нову модель/платний API не додано.
Результат моделі, де складний фон або людина впевнено позначені як предмет,
може потребувати пензля, crop або іншого фото. Сильніший поріг може прибрати
невпевнені тонкі деталі; перевіряйте їх перед збереженням. Колірне очищення
вимикається, коли колір впевненого предмета схожий на фон (зокрема біле на білому).
Значні відокремлені частини залишаються разом, тому пара взуття не зводиться
до найбільшого компонента; інший великий предмет на фото теж може залишитися.

Оригінал не зберігається постійно. Після завершення/очищення чернетки вже
видалені деталі збереженого PNG не можна відновити з відсутнього оригіналу.
Пензель «Повернути» скасовує власне стирання в поточному сеансі інструмента.

## Виконані перевірки

`python3 tools/run_host_checks.py`: **16 наборів pass**, включно з **40 новими
assertions**, що виконують production Java. Перевірено залишки, пару взуття,
однопіксельну діагональну лямку, отвір, біле на білому, строкатий фон, дві
сили очищення, незмінність RGB/джерела, наявну прозорість, NaN/некоректні
маски, buffer position, скасування й кадр 1600×1200 під `-Xmx256m`.
Перевірено білий/кремовий фон, білі принти, прозорі поля й ручний білий колір.

Це **синтетичні маски**, не вимір точності ML на фото. 3731 source/SQL checks,
11 XML, 891 локалізований рядок і 67 DAO також пройшли.
Gradle wrapper зупинився до компіляції: `UnknownHostException: services.gradle.org`.
JUnit wrapper підготовлений; Gradle JUnit, Kotlin/Compose/KSP, lint, Android,
UI/TalkBack і APK не виконані. Поточні докази — `docs/history/HOST-VALIDATION-0.13.3.json`
та `docs/history/RELEASE-VALIDATION-0.13.3.json`.

## Матриця приймання на телефоні — НЕ ВИКОНАНО

| Випадок | Що перевірити |
| --- | --- |
| Темна футболка на світлому столі | Немає ореолу/уламків; принт і шви не змінюють колір. |
| Біла сорочка на сірому фоні | Кремовий фон у картці, деталях, зумі й редакторі. |
| Біла річ на білому фоні, тіні | Не стирається тканина; при слабкій масці явне ручне виправлення. |
| Строкатий фон/вішак/людина | Перевірити сильніший режим і пензель; не зараховувати неправильну маску як прийняту. |
| Пара взуття, ремінці, мереживо | Обидва черевики/лямки збережені; просвіти справді очищені. |
| Звичайне → сильніше → звичайне | Повтор використовує доступне початкове джерело, не нарощує вирізання. |
| Повернути фото/Cancel/Back/Save | Жоден пізній результат не змінює збережене фото чи інший редактор. |
| Заміна фото, інший акаунт, пакетний імпорт | Правильна власність результату; штатні чернетки й ручне завершення. |
| Model missing/timeout/offline | Поточне фото не губиться, немає фальшивої заяви про очищений фон. |
| Перезапуск незавершеної чернетки | Збережене поточне фото придатне до ручного завершення; відсутній оригінал не вигадується. |
| Старий прозорий PNG і звичайний JPG | PNG отримує фон без міграції; суцільний JPG не називається очищеним. |
| Backup/restore, колажі, ручний пензель | PNG alpha збережена; попередні фото/історія/зв’язки не губляться. |
| Теми, UA/EN/PL, 200% шрифт, TalkBack | Читабельні кнопки, фокус, немає обрізання підказок. |
