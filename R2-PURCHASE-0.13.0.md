# R2: помічник покупки — 0.13.0

8 жовтня 2026. `0.13.0-release`, code 19, `com.familywardrobe.app`, Room/backup 8.
Джерела без нового APK. SHOP-01–03 — verify до Android-приймання. R1 збережено.

## Поведінка

«Пасує до мого гардероба?» тепер має дві вкладки: приклади образів і схожі речі.
Товар лишається закріпленим; інші складники — ваші доступні речі з урахуванням
виключень/no-repeat. Генерується до 20 прикладів, без заяви про повний перебір.
Аналіз виконується поза UI thread; застарілий результат приховується при зміні запиту.

Схожість пояснюється категорією, відомими підкатегорією/кольором/сезоном/стилем
та source URL з історії покупки. Інший гардероб не потрапляє до результатів.
Архівні/недоступні речі лишаються серед збігів із мітками. Це збіг ознак, не
розпізнавання тотожного товару за фото; внутрішній порядок не показується як відсоток.

Підкатегорію/сезон/стиль можна уточнити для поточної перевірки. Вони не
дописуються до Wish і не виводяться з назви/фото; при переході «Я купив» явні
значення передаються в існуючу чернетку purchase-review. Невідомий сезон
явно позначено: приклад не підтверджує придатність товару до погоди.

Для кожного прикладу шукається власна заміна тієї самої категорії та сезонів,
сумісних із погодою й іншими речами. Колір/стиль/посадка можуть відрізнятися.
Розрізняються доступна заміна, тимчасово недоступна й незнайдена. Можна
підставити доступну власну річ і зберегти власний образ без покупки; кандидат
залишається у «Хочу купити». Ручна заміна може бути виключеною з автоматичних
рекомендацій. Архів/прання не пропонуються для Save як готові речі.

Статистика показує кількість прикладів, уже збережених і власних речей у них.
Приклади без знайденої заміни рахуються окремо: новий wish ID або відсутність
збереженого образу не є доказом нової можливості гардероба.

Ціна й бюджет показані поряд. Порівняння лише в однаковій валюті, нуль не
підмінює відсутню суму; немає FX-конвертації, тиску чи оцінки «треба купувати».
«Відкласти рішення» повертає до списку без зміни товару, статусу чи нагадування.
«Я купив» відкриває звичайний review; history/undo та транзакції збережено.

## Перевірки та межі

15/15 host-наборів: `docs/history/HOST-VALIDATION-0.13.0.json`. 76 assertions production Java
R2, 34 assertions імпорту, 3620 source/SQL, 11 XML, 866 localized strings, 67 DAO.
Ризикові cases: unknown traits, URL variants, чужий гардероб, архів/прання,
виключення/no-repeat, pinned candidate, real partners, saved signature,
невигадана новизна, сезонні конфлікти, альтернативні layouts, 221 річ,
стабільні результати й бюджет різних валют. Знайдений випадок «усі категорії є,
але сезони несумісні» виправлено без заклику додавати нібито відсутній одяг.

Підготовлено 7 JVM/JUnit методів (6 Kotlin adapter tests і Java wrapper) та
1 Android flow test збереження planned/owned, repeat, purchase/undo/history.
Їх не виконано через недоступний Gradle bootstrap. Direct Java cases
виконані host-командою, але це не запуск Gradle JUnit або Kotlin-тестів.
Лог: `docs/history/release-evidence/0.13.0/gradle-bootstrap.log` — `Network is unreachable`.
Kotlin/Compose/KSP, lint, Android/Firebase, APK, UI і Windows/PowerShell не виконані.

## Native-приймання (усе нижче ще не виконано)

| Сценарій | Очікування |
| --- | --- |
| Перехід із wishlist/import | Той самий товар і гардероб; Back повертає контекст |
| Невідомі ознаки | Немає вигаданих сезону/стилю; ручне уточнення й очищення змінюють пояснення |
| Схожі речі | Фото, зрозумілі причини; інший гардероб ізольований; архів/прання позначені |
| Власна заміна | Товар ↔ власна річ у тому самому прикладі; недоступну не можна зберегти як готову |
| Збереження | Planned не купує товар; owned не додає товар; повтор відкриває/повертає той самий образ |
| Бюджет | Відсутні/нульові суми, однакові/різні валюти, перевищення без FX |
| Покупка | Уточнення переходять у review; save → restart → undo зберігає URL/бюджет/образи |
| Порожній стан | Брак категорії, сезонний конфлікт, filters/no-repeat, rejected combination не змішуються |
| Асинхронність | Швидке введення/зміна погоди, вихід/інший UID, пізній результат; старі дані не зберігаються |
| Доступність | 320/360/412 dp, 100/200%, UA/EN/PL, Light/Dark, TalkBack, клавіатура, 200+ речей |
| Перенос | Backup/cloud round trip saved plans/history; формат 8; без нових permissions/даних акаунта |
