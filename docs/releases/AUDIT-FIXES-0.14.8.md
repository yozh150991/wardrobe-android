## Що перевірити на пристрої

1. Колаж образу з «Натхнення»: тягнути/масштабувати/«на передній план» — без падіння.
2. Холодний старт без мережі → «Назад» на екрані відкриття → знову відкрити: сесія жива.
3. Зміна речі → закрити застосунок «Назад» → синхронізація відбувається у фоні (~1 хв).
4. Під час хмарної синхронізації навігація доступна; повторний тап показує «зачекайте».
5. Гардероб без верхнього одягу, холодна погода → є образи й підказка.
6. Редагування речі без зміни фото → імпорт того самого фото знаходить дублікат.
7. Завершений перенос у сім'ю після локальних змін — без помилки, без «Продовжити».
8. Бажана річ в образі: зміна категорії на несумісну → зрозуміла помилка.
