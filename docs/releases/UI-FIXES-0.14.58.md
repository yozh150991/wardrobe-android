# BUG-58: «Категорії», текст карток і підписи меню — 0.14.58-ui-fixes

22 листопада 2026 · Claude · 0.14.58-ui-fixes / code 88 · Room 11, формат копії 11/10 (схема й формат не змінені).
Основа: main після PR #58 (0.14.57-trends).
Джерело: два скриншоти користувача з телефона, 0.14.57 («Гардероб» англійською, «Профіль» українською). Це перші баги,
знайдені на пристрої після нового дизайну.

## Що було

- **Кнопка «Категорії» (Categories ▾)** у рядку категорій стала вузьким стовпчиком, по одній літері в рядку. Через неї
  весь рядок «Усе / Низ / Верх / Взуття» розтягнувся у висоту й зайняв пів екрана.
- **Текст під фото речі** втрачав першу літеру останнього рядка: «Bottoms · Worn: 0 days» і «Довгий рукав»
  починалися з половини літери.
- **«Хочу купити» в нижньому меню** переносилося на два рядки, і значок закладки стояв вище за значки інших вкладок.

## Чому

- **Кнопка.** З UI-03 (0.14.53) категорії стоять в одному рядку, що гортається вбік. Ширина такого рядка
  необмежена. У компактній кнопці `CategoryChoice` підпис мав `weight(1f, fill = false)`: щоб текст скорочувався, якщо
  місця мало. У рядку без межі ширини вага отримує лише мінімальну ширину кнопки (близько 58 dp мінус відступи й
  стрілка), тож текст переносився по літері.
- **Текст карток.** Картка обрізає вміст за своєю формою. Форма була та сама, що й у фото: усі кути 22 dp. Нижній лівий
  кут зрізав початок останнього рядка тексту, бо той стояв за 4 dp від краю.
- **Меню.** Підпис вкладки мав `maxLines = 2`. На вкладку припадає п'ята частина ширини екрана; зі збільшеним
  системним шрифтом «Хочу купити» не вміщалося в один рядок. Material центрує значок і підпис разом, тому два рядки
  підняли значок.
- **Чому CI не побачив.** Перевірки шукали, чи елементи є на екрані, а не як вони виміряні. Compose-тестів для цих
  екранів немає, на телефоні дизайн не перевіряли.

## Що змінено

- **Кнопка.** Підпис без ваги, в один рядок (`maxLines = 1, softWrap = false`). Компактний вигляд `CategoryChoice`
  використовується лише в рядку категорій, тож інші форми не змінилися.
- **Картка.** Фото лишилося з кутами 22 dp (`PhotoShape`). Картка й рамка вибору мають `CardShape`: верхні кути 22 dp,
  нижні 12 dp. Текст під фото має відступ 4 dp знизу, тож кут його не торкається.
- **Меню.** Новий `NavLabel` у `Ui.kt`:
  - підпис завжди в один рядок;
  - якщо хоч один підпис не вміщається, усі підписи меню разом зменшуються на 5 %, і так до 70 % (`NAV_LABEL_MIN`);
  - підпис малюється лише після того, як вмістився, тож перенесеного чи обрізаного кадру не видно;
  - розмір скидається, коли змінюються мова, підписи або кількість вкладок у ряду.

  Зі шрифтом від 1,4 меню й далі має два ряди по три вкладки, як було.

## Файли

- `ui/SelectionControls.kt` — `CategoryChoice`, компактний підпис.
- `ui/CatalogScreen.kt` — `CardShape`, форма `GarmentCard` і рамки вибору, нижній відступ тексту.
- `ui/Ui.kt` — `NavLabel`, `NAV_LABEL_MIN`, спільний `navScale` нижнього меню.
- `tools/check_catalog_design.py`:
  - у компактній кнопці й у рядку категорій немає `weight(`;
  - підпис кнопки в один рядок;
  - фото з `PhotoShape`, картка з `CardShape`, відступ тексту знизу;
  - підписи меню без `maxLines = 2`, зі спільним розміром і мінімумом 70 %.

## Перевірки

- **Host:** `check_catalog_design.py` pass. На коді 0.14.57 нові перевірки падають (8 з 8), тобто ловлять усі три баги.
- **Kotlin** локально не компілювався — збірка в CI.
- **На телефоні не перевірено.** Варто глянути «Гардероб» і нижнє меню українською, англійською й польською, зі
  звичайним і збільшеним шрифтом:
  - «Категорії» має стояти останньою кнопкою рядка, а рядок — бути звичайної висоти;
  - усі п'ять значків меню мають стояти на одній висоті.
