# Вирізання на справжніх масках — 0.14.64-cutout-cleanup

24 листопада 2026 · Claude · 0.14.64-cutout-cleanup / code 94 · Room 11, формат копії не змінено.
Основа: 0.14.63-mask-capture (PR #64 ⊃ #63); PR цієї гілки містить їх. Задача PHOTO-19, кроки 2–3.

## Що показали маски з телефону

Користувач обробив шість фото на строкатому покривалі (Galaxy S23) і передав теку `photo-debug`.

- **Маска моделі майже двійкова:** лише 0,3–0,5 % значень між 0,15 і 0,7. Результат на телефоні збігається з маскою.
  Тобто вади вносить сама модель, а не наші правила, і правила, що спираються на «невпевнені» пікселі, тут не працюють.
- **Чотири фото з шести вирізані добре.** Дві вади:
  - светр: шматок червоного покривала біля манжета, модель упевнена в ньому на 100 %;
  - сорочка: нога в кадрі, з'єднана з сорочкою вузькою «шийкою».
- **«Очистити фон сильніше» нічого не змінює.** Воно запускається на вже вирізаному фото, де фону немає, і результат
  збігається з попереднім піксель у піксель. Це окрема вада, не виправлена тут.

## Що змінилося (`PhotoCutoutRules.clean`)

Два правила після маски. Обидва лише прибирають, ніколи не додають.

| Правило | Як працює | Що захищає річ |
| --- | --- | --- |
| A. Фон на краю | Кольори, часті там, де модель упевнена у фоні, і щонайменше у 8 разів рідші в речі, прибираються від контуру всередину. Далі чистяться крихти й м'який обвід поруч | Не більше 3 % речі, інакше правило не діє зовсім (на знімках знадобилося до 1,3 %) |
| B. Чужа частина | «Тіло» речі — те, що лишається після звуження на 8,5 % від кореня з площі. Частина поза тілом прибирається, якщо вона мала (0,2–6 % площі), її кольори майже не збігаються з тілом (< 0,3) і збігаються з фоном (≥ 0,3 і вдвічі більше, ніж із тілом) | Рукав чи пасок у кольорах речі лишається; частина в кольорі, якого у фоні немає (контрастний рукав), теж |

Уже вирізані фото (без упевненого фону) правила не чіпають.

## Результат на знімках

| Фото | Прибрано додатково | Додано |
| --- | --- | --- |
| Чорний светр | 0,47 % кадру: шматок покривала біля манжета, обвід | 0 |
| Синя сорочка з листям | 0,32 %: обвід | 0 |
| Біла сорочка з дрібним малюнком | 0,16 %: обвід | 0 |
| Сорочка з пальмами | 1,50 %: нога | 0 |
| Штани | 0,33 %: обвід | 0 |
| Два «сильніші» прогони | 0 | 0 |

Усі шість переглянуто очима: тканину ніде не зачеплено. Під сорочкою лишився клаптик штанини шириною з «шийку».
Час правил на комп'ютері — 0,2–0,7 с на фото 1500 × 2000; на телефоні не виміряно.

## Обмеження

- Пороги підібрано на шести фото з одного телефону й одного тла. Це перша перевірка на справжніх даних, а не гарантія.
- Правило A може прийняти за фон оздобу на краю речі, якщо вона в одному з головних кольорів тла і менша за 3 % речі.
- Правило B не прибере чужий предмет у кольорі, якого немає у фоні, або більший за 6 % речі.
- Знімки користувача в репозиторій не додано: тести — синтетичні сцени тієї самої форми.

## Стенд

`tools/photo_stand/PhotoStand.java` запускає робочі правила на теці знімків і порівнює з результатом телефона:

```
java -m jdk.compiler/com.sun.tools.javac.Main --release 17 -d out app/src/main/java/com/familywardrobe/app/rules/PhotoCutoutRules.java tools/photo_stand/PhotoStand.java
java -cp out PhotoStand <тека photo-debug> <тека результатів>
```
