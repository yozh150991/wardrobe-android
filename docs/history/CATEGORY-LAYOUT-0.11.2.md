# Категорії на екрані — 0.11.2

Дата: 7 жовтня 2026. Version code: 17. Application ID: com.familywardrobe.app.

## Поведінка

- Швидкі фільтри категорій автоматично переходять на наступний рядок, коли бракує ширини.
- Кнопка відкриття списку має коротку назву «Категорії» та стрілку вниз.
- Вибрана категорія залишається виділеною серед швидких кнопок, навіть якщо її вибрано з повного списку.
- «Усе» скидає фільтр категорії; пошук та інші фільтри зберігаються.
- Підписи можуть переноситися; немає фіксованої висоти рядка чи обмеження числа рядків.
- Мінімальна висота кнопок — 48 dp. Для TalkBack кнопка списку повідомляє поточний вибір.
- Оновлено український, англійський і польський підписи.

## Виконана перевірка

`python tools/check_project.py`: PASS — 3305 перевірок вихідного коду/SQL,
11 XML-файлів, 791 локалізований рядок, 67 DAO-запитів.
Це перевірки ресурсів, посилань, структури коду й SQL, а не компіляція Kotlin.

Завантаження Gradle 8.11.1 у цьому середовищі зупинилося на
`java.net.SocketException: Network is unreachable`.
APK, lint, JVM/Android-тести й відображення на емуляторі для 0.11.2 не перевірено.
Результати в документах 0.11.1 стосуються попередньої версії.

## Перевірка після збірки

На екрані «Мій гардероб» перевірте ширину 320–412 dp, стандартний і збільшений
до 200% системний шрифт, мови UA/EN/PL. Усі швидкі кнопки та «Категорії» мають
вміщуватися по ширині; за потреби з'являються додаткові рядки.
Перевірте вибір довгої назви з повного списку, повернення через «Усе», пошук
категорії, закриття діалогу без вибору й збереження інших фільтрів.
Звичайна вертикальна прокрутка каталогу залишається доступною.

## Збірка

Запустіть `build-apk.ps1` у вашому оновленому проєкті. Встановіть отриманий
`app/build/outputs/apk/debug/app-debug.apk` поверх попередньої версії з тим самим
ключем підпису. Для цього оновлення достатньо перезібрати Android-застосунок.
