# Wardrobe 0.7.0 — UX-виправлення

Оновлення реалізує рекомендації дизайн-огляду в Android-коді. Нативна збірка та перегляд на телефоні ще потрібні; новий APK до пакета не входить.

## Зміни

- **Товар → моя річ.** «Я купив» відкриває перевірку фото, назви, категорії й кольору. Підтвердження атомарно створює річ, прибирає товар з активного списку та переводить посилання збережених образів на наявну річ. Ціна, валюта, посилання, натхнення й початкова потреба залишаються в деталях речі. Повторна команда повертає ту саму річ. Коротка дія «Скасувати» повертає товар; вона відмовляє, якщо річ уже змінили, відмітили носіння або виник конфлікт категорій.
- **Форми.** Основні поля речі показані першими; розмір, місце, сезон, стиль, доступність й опис розкриваються за потреби. Кнопка збереження розміщена під прокручуваними полями з урахуванням клавіатури. У товару немає порожнього великого блоку фото; сума й валюта в одному рядку, з вертикальним розміщенням при великому шрифті. Додаткові поля зберігаються в чернетці.
- **Фото.** Обробка працює паралельно із заповненням. Придатний результат автоматично центрується на прозорому квадраті; ручне повернення фону, обрізання й поворот доступні. Пізня відповідь не може замінити фото після ручної зміни, збереження або переходу. Підказки полів потребують явного застосування.
- **Каталог і образи.** Компактні пошук, фільтри й перемикач колекції; блок першого образу можна згорнути після додавання речей. Редактор і збережений образ використовують спільну композицію з вибором натисканням; при великому шрифті — послідовний список. У вкладених редакторах нижня навігація прихована.
- **Сесія.** Підтверджена Firebase-ідентичність перевіряється при холодному запуску й відкриває власне сховище без повторного введення пароля. Явний вихід і відома недійсна сесія повертають до входу. Ізоляція за project ID + UID зберігається.
- **Офлайн.** Компактний статус із повтором доступний над локальними екранами. Локальне редагування залишається доступним. Новий вхід, посилання магазину й завантаження ML-моделі залежать від мережі.
- **Мови й оформлення.** Нові тексти мають UA/EN/PL і український fallback. Попередні 11 палітр і налаштування теми збережені.

## Дані та сумісність

Room schema 4 додає `ownedId` до історії товару через міграцію 3→4. Реєструються також 1→2 і 2→3; руйнівне створення БД не використовується. Резервна копія формату 5 відновлює зв’язок історії з новими ідентифікаторами речей і підтримує старі формати 1–4. Нові копії потрібно імпортувати в 0.7.0 або новішу.

Вихідний код має versionName `0.7.0-ux`, versionCode 11. Ідентифікатор застосунку, залежності й надана конфігурація Firebase не замінені. Джерела не змінюють дані на телефоні; міграція виконається після встановлення APK з тим самим підписом. Перед установленням експортуй копію зі старої версії.

## Перевірка на тестовому Android — ще не виконана

| Сценарій | Очікувана поведінка |
| --- | --- |
| Установлення поверх 0.6.1/0.6.0 або старішої підтримуваної версії | Усі речі, фото, потреби й образи збережені; історія старих товарів порожня |
| Товар із ціною, посиланням і початковою потребою → «Я купив» | Дані перенесено в перевірку; після підтвердження одна річ і повна історія |
| Той самий товар у кількох збережених образах | Планові посилання стають посиланнями на річ; ID й назви образів збережені |
| Повторне підтвердження / конфлікт категорії в образі | Повтор не створює дублікат; конфлікт відхиляє всю покупку |
| «Скасувати» після покупки | Товар повертається; наявні й нові образи зберігаються як планові |
| Змінити річ або відмітити носіння перед скасуванням | Відмова без видалення редагувань чи носіння |
| Фото: повільний аналіз, потім Save / ручний поворот / інший редактор | Пізній результат не підміняє фінальне фото або іншу чернетку |
| Фото: прозорий PNG, біла річ, фото на людині, відсутня модель | Нормалізація без розтягування; поточне фото й повтор доступні при невдачі |
| Редагування архівної речі | Зміна полів не повертає її з архіву |
| Чернетка покупки → закриття процесу / повторний вхід | Поля й фото відкриваються в тому самому акаунті; інший UID їх не бачить |
| Холодний запуск, явний вихід, відкликаний токен, офлайн | Перевірена сесія відкриває власні дані; відома недійсна потребує входу |
| 100–200% шрифт, 320dp ширина, клавіатура, TalkBack, UA/EN/PL | Назви, сума/валюта, кнопки, помилки й композиція читаються та доступні |
| Світла/темна тема, усі палітри, пошук, фільтри, прання, архів | Стан вибору зрозумілий; фото має нейтральне полотно |
| Експорт формату 5 → окремий тестовий гардероб; імпорт старих форматів | Фото, історія покупки, валюти й зв’язки образів відновлено; поточні дані не перезаписані |

Збірка: `build-apk.ps1 testDebugUnitTest lintDebug assembleDebug`. Android-тести: `build-apk.ps1 connectedDebugAndroidTest`. Тести PurchaseFlowTest і PhotoPersistenceTest включені; тут вони не виконувалися. Деталі фактично виконаних перевірок — у VALIDATION.md.
